Built for looking, not for loading

Nexus runs on spatialscape, LIBD's open-source viewer. Everything is a static file, so a gene switch is one small request and the map never waits on a server.

Every section on one canvas

All samples of a study sit side by side under identical settings. Double-click to focus one, step through donors with ← →, switch platforms with one click.

Gene, domain and cell type at once

Color by any gene or two blended gene sets, keep spatial-domain outlines on top, and hover any cell to read its domain, cell type and expression value.

Lasso, compare, share

Draw around a region for its composition and gene statistics, export cell IDs, and send colleagues the exact view: the whole state lives in the link.

Linked modalities

Tissue on the right, nuclei on the left, one gene for both

Paired snRNA-seq references render as embeddings beside the sections. Cell type labels share one vocabulary across Xenium, RCTD weights and snRNA-seq, so a color means the same thing everywhere.

  • Spatial domains traced as outlines over gene expression
  • Filter the map to a cell type while coloring by a gene
  • Per-annotation expression table that doubles as a filter

Take the data, and the viewer, with you

  1. 1Every dataset is a plain, documented bundle you can download or read programmatically. No API keys, no accounts.
  2. 2The viewer, spatialscape, is MIT-licensed. Point it at your own bundle and it works the same way.
  3. 3Build your own bundle from AnnData or SpatialExperiment with one command and host it anywhere static files live.
pip install spatialscape
spatialscape init "visium/*/outs" -o dataset.yaml
spatialscape build dataset.yaml -o my_atlas
spatialscape serve . --port 8787
# then open the viewer with ?d=http://localhost:8787/my_atlas
