How to get the data, cite it, and build on it

Everything on Nexus is meant to be reused. This page is the single place that explains access, licensing, citation and the software behind the site.

Data access

Processed, de-identified data are public and need no account. Each dataset page and each publication lists its downloads with sizes and checksums. Three routes serve different needs:

BrowserOne click from a dataset or publication page. Fine for objects up to a few gigabytes; downloads resume if interrupted.
Command lineEvery file has a plain HTTPS URL, so curl -O, wget or rclone work, and a manifest per dataset lets you fetch all samples at once.
GlobusFor large transfers to an HPC system, every dataset is also published as a Globus guest collection. Search for “LIBD Nexus” in the Globus web app or use the per-dataset collection link.
# whole dataset, resumable
curl -O https://data.libd.org/nexus/amygdala/v1/manifest.txt
xargs -n1 curl -O --continue-at - < manifest.txt

# or one object
curl -O https://data.libd.org/nexus/amygdala/v1/amygdala_visium_spe.rds

Objects are versioned (v1.0, v1.1…) and never overwritten. The version used in a paper is archived with a DOI on Zenodo; the Nexus copy is the fast mirror.

Citing

Please cite the publication that produced the dataset, and the dataset DOI when you use the data directly. Each dataset page has a Cite button that copies both in BibTeX or plain text. If the viewer itself was useful, cite spatialscape.

Totty MS, et al. Spatial and cellular architecture of the human amygdala… (in preparation)
Dataset: Lieber Institute for Brain Development (2026). Human amygdala spatial atlas v1.0. Zenodo. doi:10.5281/zenodo.XXXXXXX
Software: Totty M. spatialscape (v0.1). https://github.com/MicTott/spatialscape

Reproducibility

Processed objects carry the exact annotations shown on Nexus, so a domain or cell type you see in the browser is the same label you get in R or Python. Build scripts that turn the analysis objects into viewer bundles are versioned alongside the data, and each bundle records the software version that produced it.

Policies & ethics

Human tissue was obtained with informed consent through the LIBD Human Brain Repository and partner brain banks under IRB-approved protocols. Processed data are shared under a CC BY 4.0 license; raw human sequencing data are available through controlled-access repositories. We ask that reuse acknowledges donors and the repository as well as the authors.

Contribute

Found an annotation that looks wrong, or built something on these data? Open an issue on the relevant repository, or write to us. LIBD groups can add a dataset to Nexus by building a bundle with spatialscape build and submitting a registry entry; the team reviews metadata and publishes it alongside the publication.

Contact

Data questions: nexus@libd.org. Viewer and bundle format: spatialscape issues.
